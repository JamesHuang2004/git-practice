# Interesting Article: Mapping the Fruit Fly Nervous System

## Article

[Researchers Publish First Complete Connectome of Fruit Fly Brain and "Spinal Cord" — Harvard Medical School](https://hms.harvard.edu/news/researchers-publish-first-complete-connectome-fruit-fly-brain-spinal-cord)

## Why I Find It Interesting

I find this article interesting because it shows how computer science and software can be used to solve problems in biology. A fruit fly has around 160,000 neurons, yet researchers were able to turn an enormous collection of biological images into a resource that other scientists can explore and use. The project also made the connectome freely available online which is cool and amazing!
